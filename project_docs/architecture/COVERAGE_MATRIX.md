# Educación Abierta Program & Subject Coverage Matrix

This matrix represents the canonical inventory of all Educación Abierta programs, subjects, and curriculum tracks administered by DGEC/MEP (Costa Rica), tracking their software modeling and content readiness state.

**Lifecycle Status Categories:**
- `NOT_STARTED`: Subject not yet explored or modeled.
- `DISCOVERED`: Official specification tables and/or practice booklets available.
- `INGESTED`: Raw artifacts normalized into machine-readable structure.
- `MODELED`: Taxonomy, domains, affirmations, and evidence catalog defined.
- `AUTHORED`: Question bank and/or lessons authored.
- `QA`: Gate A–C validation passing.
- `EDITORIAL_APPROVED`: Gate D human pedagogical/editorial signoff certified.
- `IMPLEMENTED`: Integrated into software runtime and test compilation engine.
- `VERIFIED`: Tested through automated multi-surface suites.
- `RELEASED`: Available in production to learners.
